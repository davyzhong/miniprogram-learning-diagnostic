# 钟青羽英语学科测试用例库

更新时间：2026-06-16

## 一、当前英语学科功能状态

英语学科当前不复用数学“整卷诊断 → 学习卡点 → 验证试卷”的主链路，而是围绕钟青羽个人 PEP 词库建立单词掌握闭环。

已完成的核心功能：

| 模块 | 当前状态 | 说明 |
| --- | --- | --- |
| 个人 PEP 词库 | 已完成 | 内置钟青羽 PEP 三年级到六年级上册个人词库，首页可自动导入 |
| 英语工作台 | 已完成 | 展示今日建议、今日待练、已熟悉、拼写薄弱、真正掌握、最近需要多见几次的词 |
| 单词熟悉度 | 已完成 | 每轮默认 20 词，中文/英文提示混合；孩子口头回答，AI 自动判定 |
| 纸面听写 | 已完成 | 每轮默认 20 词，AI 播放提示，孩子写在纸上，完成后拍照上传 |
| 听写纸批改 | 已完成 | 以本次 20 个候选词约束 OCR，再做确定性拼写复核 |
| 双维掌握状态 | 已完成 | `familiarity` 和 `spelling` 独立推进，`overallMastery` 派生整体掌握 |
| 错词复现与复测 | 已完成 | 错词提高抽中优先级，正确后进入 1 天、3 天、7 天复测 |
| 学习记录接入 | 已完成 | 学习记录可展示英语单词熟悉度、纸面听写和听写纸照片证据 |
| 语音“下一个” | 已完成 | 纸面听写支持“好了/下一个”辅助推进，按钮仍为主通道 |
| 入口收敛 | 已完成 | 首页只保留一个主 CTA；工具区不重复当前主任务；词库维护不再常驻首页 |
| 时态/句型 | 暂不做 | 当前阶段聚焦单词，不做时态、句型、阅读、作文 |

## 二、需求完成情况

| 需求 | 完成情况 | 验收口径 |
| --- | --- | --- |
| 英语第一阶段只做单词 | 已完成 | 英语工作台不出现数学式拍照诊断、默认试卷、学习卡点、时态句型入口 |
| 建立钟青羽个人词库 | 已完成 | 词库为空时自动导入；导入后展示 505 个词库统计 |
| 每次默认 20 个词 | 已完成 | 单词熟悉度和纸面听写均生成 20 词 session |
| 单词熟悉度：听中文/英文后口头回答 | 已完成 | 逐题提交识别文本和 `durationMs`，只更新 `familiarity` |
| 纸面听写：纸上作答后拍照上传 | 已完成 | 上传照片后写入 `photoFileIds` 和整场 `durationMs` |
| AI/OCR 自动判定，暂不人工确认 | 已完成 | 纸面听写调用 `analyzeDictationPhoto`，逐词输出 correct/incorrect/unclear |
| 不确定不算错 | 已完成 | `unclear` 只保留证据，不更新正误计数 |
| 弱词复现和间隔复测 | 已完成 | 抽词优先级覆盖双维薄弱、当前维薄弱、到期复测、跨维补盲、新词 |
| 学习记录展示英语过程 | 已完成 | 时间线显示英语单词熟悉度、英语纸面听写、听写纸照片 |
| 不新增功能，只优化可用性 | 已完成 | 英语工作台改为“今日建议 + 继续练习 + 学习记录”，减少重复入口 |
