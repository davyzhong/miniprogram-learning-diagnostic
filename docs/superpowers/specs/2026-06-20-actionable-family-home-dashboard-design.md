# 可操作家庭首页行动看板设计

日期：2026-06-20

> 2026-06-20 落地补充：家庭页方案已扩展为“家庭与个人学习工作台”双页重构。个人页新增个人插图、今日行动、最新诊断报告、行动队列和三科学科入口，详见 [家庭与个人学习工作台重构落地设计](./2026-06-20-actionable-family-and-personal-workbenches-design.md)。

## 背景

当前多孩子首页已经从单人“学习档案首页”演进为“家庭学习工作台”。页面上会同时展示钟青羽和钟筱雨两个孩子的学习状态。

现有实现里，每个孩子卡片包含状态数字、学科摘要、最近试卷和下一步行动。其中“最近试卷”会把验证卷编号、题量、覆盖卡点全部拼成一段长文本。数学学习卡点升级为细颗粒度后，这段文本会非常长，导致首页出现信息拥挤但不可操作的问题。

本设计采用 B++ 方案：**行动优先 + 高信息密度 + 每个区块都可点击**。首页不再只是状态展示，也不是最近记录列表，而是一个可操作索引：家长打开首页后，既能看到足够多的信息，也能直接进入下一步动作。

## 设计目标

1. 首页优先回答“今天该做什么”，而不是“最近发生了什么”。
2. 在只有两个孩子的场景下，提高首页信息密度，充分利用页面空间。
3. 每个展示区块都必须有明确点击动作，避免只读信息块。
4. 长细卡点列表不在首页展开，只展示短摘要；完整内容进入卡点中心、学科工作台或报告页。
5. 首页保留证据追溯入口，让家长能快速进入诊断报告、验证卷、知识地图和学习记录。
6. 孩子排序固定为钟青羽在前，钟筱雨在后。

## 首页定位

首页名称仍为“家庭学习工作台”。

首页信息顺序：

1. 页面标题与“添加孩子”入口
2. 钟青羽孩子卡片
3. 钟筱雨孩子卡片

每个孩子卡片内部顺序：

1. 孩子基本信息
2. 状态数字
3. 今日优先行动
4. 二级待办
5. 三科学习状态
6. 快捷入口

## 孩子排序

短期使用前端确定性排序：

1. 名字为“钟青羽”的孩子固定第一。
2. 名字为“钟筱雨”的孩子固定第二。
3. 其他孩子按 `createdAt` 倒序兜底。

后续如果孩子数量增加，再在 `students` 中引入 `displayOrder` 字段，不作为本轮必要条件。

## 卡片结构

### 1. 孩子基本信息

展示：

```text
钟青羽  26 项待处理
6年级 · 家庭档案 · 最近更新 6小时前 · 查看档案
```

点击动作：

- 点击头像、姓名、卡片顶部或箭头：进入 `student-profile`。

### 2. 状态数字

展示四个状态：

```text
0 分析中
11 待验证
15 待上传
0 已改善
```

点击动作：

| 区块 | 动作 | 目标 |
| --- | --- | --- |
| 分析中 | 查看正在分析的任务 | `learning-records?filter=analyzing` |
| 待验证 | 查看待验证卡点 | `bottleneck-center?filter=active` |
| 待上传 | 查看待上传验证卷 | `learning-records?filter=pending-upload` |
| 已改善 | 查看已改善卡点 | `bottleneck-center?filter=improved` |

### 3. 今日优先行动

这是孩子卡片里最高优先级的操作。

示例：

```text
今日优先行动
上传数学验证卷作答照片
数学-20260620-01 · 17页 · 59题。可以分批做，任意页完成后先拍照上传。
进入试卷
```

点击动作：

- 如果存在待上传验证卷：进入 `paper-preview`。
- 如果没有待上传验证卷但存在待验证卡点：进入对应学科验证卷生成入口。
- 如果英语存在可练习词库任务：进入英语认词练习或英语工作台。
- 如果没有任何任务：进入上传页或学科工作台，提示上传第一份作业。

优先级：

1. 待上传验证卷
2. 待验证卡点
3. 语文具体错项复习/复测
4. 英语认词或纸面听写
5. 上传第一份作业

### 4. 二级待办

展示主行动之外的 1 到 2 个后续动作。

示例：

```text
下一项：语文复测
进入语文错项复习/复测页。

英语入口：认词练习
进入英语个人词库练习。
```

点击动作：

- 点击二级待办：进入对应任务页。
- 如果任务没有专属页，则进入对应 `subject-home`。

### 5. 三科学习状态

每个孩子展示数学、语文、英语三行。

示例：

```text
数学  8 待办
重点：计算、面积单位、分数；点击进入数学工作台。

语文  3 待办
错项：拼音笔顺、识字词语；点击进入语文工作台。

英语  0 记录
未开始；点击进入英语工作台或认词练习。
```

点击动作：

- 数学行：进入数学 `subject-home`。
- 语文行：进入语文 `subject-home`。
- 英语行：优先进入英语工作台；如果后续已有认词练习快捷页，可升级为进入认词练习。

摘要规则：

- 每科最多展示 2 到 3 个短关键词。
- 数学从当前细卡点归并后的可读名称取摘要，例如“计算、面积单位、分数”。
- 语文优先展示具体错项类型，例如“拼音笔顺、识字词语”。
- 英语展示当前学习资产状态，例如“未开始”“认词练习待完成”“听写待上传”。

### 6. 快捷入口

展示四个入口：

```text
最新诊断
当前试卷
知识地图
学习记录
```

点击动作：

| 入口 | 动作 | 目标 |
| --- | --- | --- |
| 最新诊断 | 打开最新有效诊断报告 | `report` |
| 当前试卷 | 进入当前验证卷预览、下载或上传 | `paper-preview` |
| 知识地图 | 查看知识节点、卡点和资源 | `knowledge-map` |
| 学习记录 | 查看完整时间线 | `upload-history` |

如果某个入口没有数据：

- “最新诊断”：显示“暂无诊断”，点击进入上传页。
- “当前试卷”：显示“暂无试卷”，点击进入学科工作台或验证卷生成入口。
- “知识地图”：数学可进入知识地图；其他学科暂时进入学科工作台。
- “学习记录”：始终可进入时间线；空状态由时间线页面处理。

## 钟筱雨轻量状态

钟筱雨目前没有完整学习数据时，不应显示空白卡片。

展示：

```text
钟筱雨  无待办
低年级 · 暂无更新 · 查看档案

上传第一份作业
进入上传页，建立学习档案。

查看学科入口
数学、语文、英语均未开始。
```

点击动作：

- “上传第一份作业”：进入上传页，默认可先选数学或语文。
- “查看学科入口”：进入学习档案或学科选择/学科工作台。

## 数据来源

首页继续使用当前数据聚合方式：

- `students`
- `subjectProfiles`
- `recentReports`
- `recentPapers`

本轮重点在前端 presenter 生成更合适的 view model，不新增数据库集合。

需要扩展的 view model 字段：

```js
{
  priorityAction: {
    title,
    summary,
    actionText,
    url,
    tone
  },
  secondaryActions: [
    { title, summary, url, subject, type }
  ],
  subjectRows: [
    { key, name, summary, statusText, url }
  ],
  quickLinks: [
    { key, title, summary, url, disabled }
  ]
}
```

现有字段兼容：

- `nextAction` 可作为 `priorityAction` 的兼容来源。
- `latestValue` 不再作为首页主展示块；可拆入 `quickLinks.currentPaper` 或 `quickLinks.latestReport`。

## 交互原则

1. 不展示不可点击的“装饰性信息块”。
2. 每个数字、学科行、快捷入口、行动卡都必须可点击。
3. 首页点击目标要直接，不要多跳：
   - 能进试卷就进试卷。
   - 能进报告就进报告。
   - 能进筛选列表就带 filter。
4. 长内容必须收敛：
   - 卡点摘要最多 2 到 3 个关键词。
   - 验证卷只展示编号、页数、题量，不展示完整覆盖细卡点。
5. 视觉上可以信息密度高，但每块都要有边界、标题和动作暗示。

## 视觉方向

沿用当前蓝色体系和圆角卡片风格。

变化点：

- “最近试卷”长文本块替换为“快捷入口”四宫格。
- “下一步”升级为“今日优先行动”，使用浅橙背景突出。
- 二级待办使用浅色小卡，不抢主行动。
- 状态数字保留，但每个数字下面增加点击暗示或可点击态。
- 钟青羽卡片信息完整；钟筱雨卡片轻量但可操作。

## 验收标准

1. 首页孩子顺序固定为钟青羽在前、钟筱雨在后。
2. 首页不再出现长篇“最近试卷覆盖卡点”文本。
3. 钟青羽卡片包含：
   - 状态数字
   - 今日优先行动
   - 二级待办
   - 三科学习状态
   - 四个快捷入口
4. 每个可见区块都有点击目标。
5. 待上传验证卷存在时，今日优先行动进入验证卷预览/上传页。
6. 数学/语文/英语行分别进入对应学科工作台。
7. 快捷入口分别进入报告、试卷、知识地图、学习记录。
8. 钟筱雨即使暂无学习数据，也有“上传第一份作业”和“查看学科入口”动作。
9. 单元测试覆盖 presenter 生成的关键 view model。
10. 页面测试覆盖主要点击路由。

## 暂不进入本轮

- 新增 `displayOrder` 数据字段。
- 新建独立“今日待办”集合。
- 全新首页视觉重做。
- 复杂拖拽排序或孩子管理排序配置。
- 英语认词练习的深层页面重构。
