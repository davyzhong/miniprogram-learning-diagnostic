# Family Learning Workflow

> Status: active product reference  
> Updated: 2026-07-18

> Current implementation note: the family home now places one-row quick actions and each subject's latest formal diagnosis before priority actions, compact metrics, and subject status. The personal profile expands diagnosis evidence; AI usage remains a family-home-level entry only.

## 1. Workflow Goal

The family workflow turns a diagnosis report into a short, repeatable learning session.

The mini program should help the parent answer:

```text
Which one bottleneck should we handle today?
What evidence says it matters?
What should the child do on paper?
How do we know whether it improved?
```

## 2. Recommended 15-20 Minute Session

1. Pick one active bottleneck.
2. Review the original evidence.
3. Ask the child to explain the error in their own words.
4. Use one learning resource or worked example if needed.
5. Complete 2-5 focused practice items.
6. Ask the child to self-check with a fixed checklist.
7. Schedule a verification or spaced review.
8. Record whether the bottleneck is still active, unclear, improved, or needs more evidence.

## 3. Parent-Facing Rules

- One session should fix one small bottleneck, not a whole chapter.
- Do not start with a long lecture.
- Do not treat every error as carelessness.
- Do not mark improvement unless the verification evidence is clear.
- Keep the child on the selected material; do not send them into an open recommendation feed.

## 4. Child Evidence To Preserve

Paper evidence is valuable because it shows:

- Original answer.
- Intermediate steps.
- Scratch work.
- Crossed-out changes.
- Teacher marks.
- Parent correction color.
- Verification answer and later correction.

The upload flow should continue to preserve this evidence chain whenever possible.

## 5. Product Implications

The mini program needs to make these actions easy:

- Choose one next bottleneck.
- Generate a printable paper or learning pack.
- Show why the target matters.
- Keep page and target identifiers traceable.
- Let parents upload only the completed page.
- Record blank, unclear, wrong, partial, and correct evidence separately.
