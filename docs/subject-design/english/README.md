## Current Product Boundary

当前英语学科不做“大英语学习系统”，只做词汇掌握闭环：

- 个人词库：以钟青羽的 PEP 词库为基础，后续可补充小学常用词。
- 认词练习：看中文或英文提示，孩子口头回答对应内容，AI 自动判定。
- 纸面听写：看提示写在纸上，完成后拍照上传，按词判定拼写掌握。
- 错词本：集中处理高频错词、会认不会写、不熟词和待复测词。
- 学习记录：保留认词、听写和听写照片证据，形成可追踪时间线。

当前暂不做：

- 发音评分；
- 听力专项训练；
- 时态和句型专项；
- 阅读理解；
- 作文表达；
- 英语整卷拍照诊断；
- 类似数学的英语“学习卡点”体系。
