# 知识地图外显设计文档

> 版本：v0.1
> 日期：2026-06-18
> 状态：DRAFT（待审阅）
> 定位：把知识地图从"深埋 6 层的教学工具"变成"外显的学习导航核心"

## 一、当前问题（4 个维度）

| 维度 | 现状 | 目标 |
|------|------|------|
| **入口太深** | 首页→档案→学科→卡点→详情→资源（6 层） | 首页直接可见，1-2 层到达 |
| **语言太学术** | "summary/concept/worked_example" | "孩子哪里不会→怎么看→怎么练" |
| **流程太分散** | 5 段碎片模块，上下翻 | 连贯故事线：发现→讲解→练习→视频 |
| **没有地图感** | 纯文字列表 | 图形化知识结构，直观看到进度 |

## 二、设计决策（已确认）

| 决策 | 选择 |
|------|------|
| 入口位置 | 首页卡片 + 报告页嵌入 + 独立入口（三路并进） |
| 语言风格 | 口语化（面向家长，不是教学大纲） |
| 内容流程 | 连贯故事线（发现→看讲解→做练习→看视频） |
| 地图感 | 图形化卡片 + 进度可视化 |

## 三、入口重新设计（三路并进）

### 3.1 首页卡片入口（1 层到达）

首页（index）现有"重点提示"区域下方，新增一个**知识地图卡片**：

```
┌─────────────────────────────────────┐
│  🗺️ 本周学习地图                      │
│                                       │
│  数学 · 3 个待修复卡点                 │
│  ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐     │
│  │ ✅ │ │ 🔴 │ │ 🔴 │ │ ⬜ │ │ ⬜ │     │
│  │分数 │ │小数 │ │比例 │ │几何 │ │统计 │ │
│  └───┘ └───┘ └───┘ └───┘ └───┘     │
│                                       │
│  点击查看详细地图 →                    │
└─────────────────────────────────────┘
```

- 每个方块代表一个知识领域
- ✅ 已掌握 / 🔴 待修复 / ⬜ 未诊断
- 点击进入知识地图详细页（1 层）

### 3.2 报告页嵌入（0 层增量）

诊断报告完成后，报告页底部直接展示**知识地图快照**：

```
诊断报告
  ↓ 报告内容
  ↓ （现有"下一步"区域）
┌─────────────────────────────────────┐
│  🗺️ 知识地图更新                      │
│                                       │
│  本次诊断发现 3 个卡点：                │
│  🔴 小数乘法小数点定位                  │
│     → 点击查看讲解和练习                │
│  🔴 异分母通分错误                      │
│     → 点击查看讲解和练习                │
│  🟡 分数除法倒数（改善中）              │
│     → 点击查看讲解和练习                │

```

不再需要"卡点详情→点学一下→学习资源"三步跳转——报告页直接展示卡点入口。

## 四、语言口语化改造

### 4.1 模块标题改名

| 原标题（学术化） | 新标题（口语化） |
|-----------------|-----------------|
| 今天补什么（summary） | **孩子哪里不会** |
| 为什么会错（concept） | **为什么会这样想** |
| 例题拆解（worked_example） | **这样做才对** |
| 常见错误对比（common_mistake） | **别再这样做了** |
| 马上练 3 题（practice） | **试一试** |

### 4.2 内容语气

改前（学术）：
> 这个卡点会影响小数乘法相关题目的稳定性。典型症状：小数乘法积的小数位数错误。

改后（口语）：
> 孩子算 0.25 × 0.4 的时候，经常把小数点点错位置。这不是粗心——他还没搞清楚"两个因数一共有几位小数，积就保留几位"这个规则。

## 五、流程连贯化

### 5.1 当前流程（碎片）

```
5 个独立模块，平行排列，用户自由翻
summary → concept → worked_example → common_mistake → practice
```

### 5.2 改后流程（故事线）

```
一条连贯的引导线：

1. 🔍 发现问题
   "孩子上次在这道题上出错了：0.25 × 0.4 = 0.1（写成了 0.01）"
   "原因：他把两个因数的小数位数直接相加，但忘记在积的末尾补零。"

2. 💡 这样做才对
   "正确做法：先数两个因数共有几位小数（0.25 有 2 位 + 0.4 有 1 位 = 3 位），
    再算整数积 25 × 4 = 100，最后点 3 位小数 → 0.100 = 0.1"

3. ⚠️ 别再这样做了
   "常见错误：只数了 0.25 的 2 位小数，忘记 0.4 也有 1 位 → 结果写成 0.10"

4. ✏️ 试一试（3 题，难度递进）
   第1题：0.3 × 0.2 = ？（基础）
   第2题：1.25 × 0.8 = ？（进阶）
   第3题：判断 0.12 × 0.5 的结果接近 6、0.6 还是 0.06？（估算）

5. 📺 想看完整讲解？（外部资源区）
   B站 · 小数乘法专项精讲 → [打开观看]
```

每一步用引导性语言衔接，不是一个冷冰冰的模块列表。

## 九、风险

| 风险 | 缓解 |
|------|------|
| 首页卡片太占空间 | 只在有诊断数据时显示，无数据不显示 |
| 知识地图页数据量大 | 按需加载：先显示领域汇总，点击展开才加载节点 |
| 口语化内容质量 | LLM prompt 约束语气 + 缓存后人工审核 |
