# 学科设计文档索引

本目录用于沉淀不同学科在学习诊断小程序中的独立设计逻辑，供后续开发者、产品协作者或其他 AI 快速理解项目背景、功能边界、数据现状和追踪方法。

当前已整理：

| 学科 | 文档 | 当前定位 |
| --- | --- | --- |
| 数学 | [钟青羽数学学科设计文档.md](./钟青羽数学学科设计文档.md) | 纸笔试卷诊断主链路：拍照诊断、学习卡点、验证试卷、趋势追踪 |
| 英语 | [钟青羽英语学科设计文档.md](./钟青羽英语学科设计文档.md) | 正式版：个人 PEP 词库 + 单词熟悉度 + 纸面听写双功能闭环 |
| 英语 | [钟青羽英语双功能闭环设计规格.md](./钟青羽英语双功能闭环设计规格.md) | 开发与测试规格：双维状态机、联动抽词、候选词约束 OCR |
| 英语 | [钟青羽英语双功能闭环技术实现文档.md](./钟青羽英语双功能闭环技术实现文档.md) | 工程实现规格：数据模型、云函数 API、页面职责、迁移与测试 |

阅读建议：

1. 先读数学文档，理解整个 MVP 的“证据链 + 学习卡点 + 验证闭环”。
2. 再读英语正式文档，理解为什么英语不复用数学整卷诊断，而是围绕个人词库做“熟悉度 + 纸面听写”。
3. 需要理解英语 v2 规则时，再读英语双功能闭环规格，重点看双维状态机、单次会话单功能、P3 补盲区联动抽词和候选词约束 OCR。
4. 需要真正改代码时，再读英语技术实现文档，按数据模型、云函数 API、页面职责、迁移策略和测试计划落地。
5. 英语板块的产品与技术背景另见根目录 `24-英语学习APP竞品调研与板块设计启示.md`、`25-英语板块口语听力技术可行性与决策分析.md`。
6. 需要查看系统实现时，再读 `../ARCHITECTURE.md`、`../DATA_DICTIONARY.md` 和 `../CLOUD_FUNCTIONS.md`。
