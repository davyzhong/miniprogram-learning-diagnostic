# 知识地图资源展示设计文档

> 版本：v0.1
> 日期：2026-06-18
> 状态：APPROVED（已确认设计决策，待实现）
> 定位：在 learning-resource 页呈现"C 本地讲解 + A 外链跳转"组合，让知识地图资源真正可用

## 一、背景与动机

### 当前痛点

1. **外部资源只存不用**：`learning-resources.seed.json` 有 28 条优质资源（B站/Khan），但 `learning-resource` 页只渲染本地文字模块，`externalResources` 完全不展示。
2. **唯一的出口体验差**：报告页（report）点击资源 → 复制链接到剪贴板 → 提示"请到 XX 平台打开"。用户要手动切 App、粘贴、打开。
3. **本地内容质量不均**：`resource-pack-generator.js` 的 5 段模块只有小数乘法有定制练习，其他卡点是泛泛模板。

### 目标

```
用户进入卡点详情 → 点"学一下" → learning-resource 页
  上半部分：本地讲解（方案 C）— 5 段增强后的内容
  下半部分：外部参考（方案 A）— 卡片化资源 + 一键跳转
```

## 二、已确认的设计决策

| 决策点 | 选择 |
|--------|------|
| 展示位置 | learning-resource 页底部加"外部参考"区域 |
| 跳转方式 | B站/小红书 → 跳转小程序；其他 → 复制链接 |
| 本地内容来源 | 现有 taxonomy 数据 + LLM 增强 + 缓存 |
| 资源优先级 | B站 > 小红书 > 国家中小学智慧教育平台 > 可汗中文版 > 其他 |

## 三、资源平台优先级

## 四、本地内容增强（方案 C）

### 4.1 增强流程

```
进入资源页 → 查 learningResourcePacks 缓存
  → 有缓存且 cacheVersion 匹配 → 直接用
  → 无缓存或版本过期 → buildResourcePackDraft（现有 taxonomy 数据）
    → 调 LLM 增强 5 段内容深度
    → 存入 learningResourcePacks（带 cacheVersion + enhancedAt）
    → 返回
```

### 4.2 五段内容增强方向

| 模块 | 现状 | 增强后 |
|------|------|--------|
| `summary` 今天补什么 | 只有一句卡点名 | 加一句"为什么这个卡点重要"的说明 |
| `concept` 为什么会错 | `symptomPatterns[0]` | 列出 2-3 个典型错误场景，每个附"为什么会这样想" |
| `worked_example` 例题拆解 | 泛泛模板题 | 从 microValidationRules 提取一道具体验证题 + 分步解题过程 |
| `common_mistake` 常见错误对比 | 只有一句 | 对比"错误做法 vs 正确做法"，附判断方法 |
| `practice` 马上练 3 题 | 只有泛泛题 | 从该 BN 卡点的 evidence 数据提取真实错题变体 |

### 4.3 LLM 增强 prompt 设计

```
你是数学老师，为以下学习卡点生成讲解内容（面向家长辅导六年级孩子）。

卡点：BN-DEC-MUL-POINT-COUNT（小数乘法小数点定位）
典型症状：分数加减时分母直接相加
验证规则：给小数乘法题，检查积的小数位数

请生成：
1. summary（一句话说明为什么这个卡点重要）
2. concept（2-3 个典型错误场景，每个附"为什么会这样想"）
3. worked_example（一道具体题目 + 分步解题过程，写出每一步的判断）
4. common_mistake（错误做法 vs 正确做法对比）
5. practice（3 道练习题，难度递进，附答案和思路）

直接返回 JSON，不要包裹 markdown。
```

### 4.4 缓存策略

```js
// learningResourcePacks 文档新增字段
{
  cacheVersion: 1,         // 数据格式版本，taxonomy 更新时递增
  llmEnhanced: true,       // 是否经过 LLM 增强
  enhancedAt: Date,        // 增强时间
  blocks: [/* 增强后的 5 段内容 */],
}
```

当 `bottleneck-taxonomy-v2.seed.json` 更新后（版本号变化），`cacheVersion` 不匹配时自动重新生成。

### 5.2 跳转逻辑

```js
// miniprogram/utils/cloud.js 新增
function openExternalResource(platform, url, title) {
  if (platform === 'B站') {
    // 方案1：跳转 B站小程序（需要 appId）
    wx.openEmbeddedMiniProgram({
      appId: 'BILIBILI_APPID', // 需确认实际 appId
      path: `pages/video/video?bvid=${extractBvid(url)}`,
      fail: () => fallbackCopyLink(url, platform)
    })
  } else if (platform === '小红书') {
    wx.openEmbeddedMiniProgram({
      appId: 'XHS_APPID',
      fail: () => fallbackCopyLink(url, platform)
    })
  } else {
    fallbackCopyLink(url, platform)
  }
}

function fallbackCopyLink(url, platform) {
  wx.setClipboardData({
    data: url,
    success: () => wx.showToast({ title: `链接已复制，请到${platform}打开`, icon: 'none' })
  })
}
```

## 八、风险与注意事项

| 风险 | 缓解 |
|------|------|
| B站/小红书小程序 appId 未知 | 先用复制链接降级，拿到 appId 后升级为跳转 |
| LLM 增强内容质量不可控 | 加缓存后人工审核一轮，标注 `reviewStatus: 'parent_reference'` |
| 外部链接失效 | 加 `lastCheckedAt` 字段，定期校验 |
| 平台优先级主观 | 可配置，家长可在设置里调整偏好 |
