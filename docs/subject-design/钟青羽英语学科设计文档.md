## 1. 整套背景

### 1.1 英语学科为什么需要独立设计

数学链路的核心证据来自纸笔过程：列式、演算、单位、订正和验算都能在卷面中被观察。因此数学适合“拍照试卷 → AI 诊断学习卡点 → 生成验证试卷 → 拍照复测”的纸面诊断闭环。

英语当前阶段的主要问题不同。钟青羽英语学习中更明显的短板集中在：

- 单词是否熟悉；
- 听到英文能否理解中文含义；
- 看到或听到中文能否调出英文；
- 英文读音是否熟悉；
- 最终能否把单词准确写下来。

因此，英语不应简单复用数学的试卷诊断链路。英语第一阶段最适合围绕“个人词库”和“单词掌握”建立一个更轻、更高频的闭环。

### 1.2 从 v1 到 v2 的演进

v1 的英语设计只有一个核心功能：基于个人 PEP 词库做 20 词语音听写，由孩子口头拼读，系统自动判定。

经过进一步讨论后，v1 暴露出一个关键问题：一个单词“认识”和“写对”不是同一件事。

孩子可能：

- 听到 `science` 知道是“科学”，但不会拼写；
- 看到“星期三”能说出 `Wednesday`，但写成 `Wensday`；
- 能口头回答英文，但纸面书写时漏字母；
- 能在熟悉度测试中答对，但考试听写时仍写错。

所以 v2 将英语单词掌握拆成两个核心功能：

```text
功能 1：单词熟悉度
AI 说中文或英文，孩子口头说出另一个对应内容

功能 2：纸面听写
AI 说中文或英文，孩子在纸上写出完整英文单词，完成后拍照上传识别
```

这两个功能共同构成“会认 + 会写”的英语单词掌握闭环。

### 1.3 个人词库来源

英语听写不能随机抽取市面词库，而必须围绕钟青羽当前教材体系。项目已将以下资料作为个人 PEP 词库来源：

- `PEP三年级上下册 英语单词句型表.pdf`
- `PEP四年级上册 英语单词句型表.pdf`
- `PEP四年级下册 英语单词句型表(1)(1).docx`
- `PEP五年级上册 英语单词句型表.pdf`
- `PEP五年级下册 英语单词句型表.pdf`
- `PEP六年级上册 英语单词句型表.pdf`

当前已经生成结构化词库，覆盖三年级上册到六年级上册，共 505 条单词和教材词组。

### 1.4 当前范围边界

当前阶段只做英语单词掌握，不做“大英语学习系统”。

明确不做：

- 时态专项；
- 句型专项；
- 阅读理解；
- 作文表达；
- 英语整卷拍照诊断；
- 类似数学的英语学习卡点分类体系。

当前只做：

- 个人 PEP 词库；
- 单词熟悉度；
- 纸面听写；
- AI/规则判定；
- 错词强化；
- 间隔复测；
- 掌握状态追踪。

## 2. 设计思路

### 2.1 英语单词掌握的核心闭环

英语 v2 的核心闭环是：

```text
个人 PEP 词库
↓
单词熟悉度测试
↓
发现不熟词 / 已熟悉但未验证拼写的词
↓
纸面听写
↓
拍照上传听写纸
↓
OCR + 候选词约束匹配
↓
更新熟悉度和拼写状态
↓
错词提高出现频率
↓
1 天 / 3 天 / 7 天复测
↓
两维都稳定后标记为真正掌握
```

### 2.2 两个功能测不同维度

| 功能 | 孩子做什么 | 主要考察 | 证据来源 |
| --- | --- | --- | --- |
| 单词熟悉度 | AI 说中文或英文，孩子口头说出另一个对应内容 | 听力理解、词义熟悉、口头产出、发音 | 语音识别文本 |
| 纸面听写 | AI 说中文或英文，孩子在纸上写英文单词 | 拼写准确性、字母顺序、漏字母、书写稳定性 | 听写纸照片 OCR |

“单词熟悉度”不能证明孩子会写；“纸面听写”才能证明拼写是否稳定。

### 2.3 单词状态必须双维追踪

v1 只有一个 `masteryStatus`，会导致状态打架。例如一个词在口头熟悉度里答对，但在纸面听写里写错，如果两个功能都更新同一个状态，系统无法解释这个词到底是“会认不会写”，还是“完全不熟”。

v2 采用双维状态：

```text
familiarity  熟悉度维度：单词熟悉度功能更新
spelling     拼写维度：纸面听写功能更新
```

一个单词只有在两个维度都稳定通过后，才算真正掌握。

### 2.4 单次会话只做一个功能

一次会话只做一种任务：

- 要么全是“单词熟悉度”；
- 要么全是“纸面听写”。

这样孩子体验稳定，家长也容易理解本次训练目的。两个功能的联动不体现在同一场会话里混合题型，而体现在后续抽词：例如“熟悉度已掌握但拼写未测”的词，会优先进入纸面听写。

### 2.5 判定三态

两个功能都使用三态判定：

| 判定 | 含义 | 是否更新状态 |
| --- | --- | --- |
| `correct` | 明确答对或写对 | 更新为正确记录，推进复测 |
| `incorrect` | 明确答错或写错 | 更新为薄弱记录，提高复现频率 |
| `unclear` | 语音识别失败、环境噪音、OCR 不清楚或无法对应 | 不计对错，本轮或后续重测 |

`unclear` 不能算错，这是保护孩子和数据质量的关键规则。

| 语音插件配置 | 已接入微信同声传译插件 | `app.json`、`english-practice` |

### 3.2 v2 新增功能一：单词熟悉度

目标：判断孩子是否认识这个词、听得懂、能说出对应含义或英文。

支持两种方向：

| 方向 | AI 提示 | 孩子回答 | 判定依据 |
| --- | --- | --- | --- |
| `cn2en` | 中文释义，如“科学” | 英文单词，如 `science` | 语音识别英文是否匹配目标词 |
| `en2cn` | 英文发音，如 `science` | 中文释义，如“科学” | 语音识别中文是否匹配标准释义或同义词 |

功能要求：

- 每次默认 20 个词；
- 单次会话只做熟悉度；
- `cn2en` 和 `en2cn` 可混合，也可按策略轮换；
- `unclear` 的词不更新状态，可在本轮末尾重测；
- 只更新 `familiarity` 维度；
- 不直接判定单词已掌握。

### 3.3 v2 新增功能二：纸面听写

目标：判断孩子能否在纸上完整写对英文单词。

流程：

```text
系统生成 20 个词
↓
AI 逐个播报中文释义或英文发音
↓
孩子在纸上写英文单词
↓
孩子点击“下一题”或说“好了/下一个”
↓
全部完成后拍照上传听写纸
↓
系统识别纸面答案并判定每个词 correct / incorrect / unclear
↓
只更新 spelling 维度
```

功能要求：

- 每次默认 20 个词；
- 需要清晰提示“一行一个词，按顺序写”；
- 主要节奏控制用按钮，“好了/下一个”作为辅助；
- 上传后复用现有图片分析能力，但 prompt 和判定逻辑应改为“听写纸识别”；
- OCR 不做开放式猜测，而是在本次 20 个候选词内进行约束匹配；
- 不清楚或无法对应的词标记 `unclear`，不直接算错。

### 3.4 v2 工作台功能

英语工作台应从“单一听写入口”升级为“双任务工作台”：

| 区域 | 内容 |
| --- | --- |
| 今日建议 | 系统推荐今天先做熟悉度还是纸面听写 |
| 单词熟悉度入口 | 快速口头练习，适合每天高频进行 |
| 纸面听写入口 | 需要纸和笔，完成后拍照上传 |
| 统计卡片 | 词库总数、已熟悉、拼写薄弱、今日复测、真正掌握 |
| 高频问题 | 不熟词、拼写错词、今天复测词 |
| 学习记录 | 后续展示熟悉度会话、听写照片、听写判定结果 |

### 3.5 v2 云函数能力

现有 `englishVocabulary` 云函数继续作为主入口，建议扩展 action：

| action | 作用 |
| --- | --- |
| `generateRecognitionSession` | 生成单词熟悉度会话 |
| `submitRecognitionAttempt` | 提交单题口头回答，更新 `familiarity` |
| `generatePaperDictationSession` | 生成纸面听写会话和读词队列 |
| `submitDictationPhoto` | 上传听写纸照片后触发 OCR 分析 |
| `analyzeDictationPhoto` | 对听写纸做候选词约束匹配 |
| `getVocabularySummary` | 返回双维统计摘要 |

也可以在第一版实现中继续复用 `generatePracticeSession`，用 `functionType` 或 `type` 区分 `familiarity` 和 `spelling`，避免集合过早膨胀。

## 5. 单词掌握追踪趋势

### 5.1 两个维度独立运行同一套状态机

`familiarity` 和 `spelling` 各自拥有独立状态：

| 状态 | 含义 |
| --- | --- |
| `untested` | 该维度尚无有效判定 |
| `needs_practice` | 该维度答错或写错，需要强化 |
| `reviewing` | 该维度已答对，进入间隔复测 |
| `mastered` | 该维度已连续通过复测 |

状态转移规则：

```text
untested
  ├─ correct → reviewing，correctCount = 1，nextReviewAt = +1 天
  ├─ incorrect → needs_practice，wrongCount +1，nextReviewAt = +1 天
  └─ unclear → 状态不变，本轮或后续重测

needs_practice
  ├─ correct → reviewing，correctCount = 1，nextReviewAt = +1 天
  ├─ incorrect → needs_practice，wrongCount +1
  └─ unclear → 状态不变，本轮或后续重测

reviewing
  ├─ 第 2 次 correct → nextReviewAt = +3 天
  ├─ 第 3 次 correct → nextReviewAt = +7 天
  ├─ 第 4 次 correct → mastered
  ├─ incorrect → needs_practice，correctCount = 0
  └─ unclear → 状态不变，本轮或后续重测

mastered
  └─ incorrect → needs_practice，correctCount = 0
```

### 5.2 综合掌握状态

`overallMastery` 是派生状态：

| 条件 | 综合状态 |
| --- | --- |
| 两维都是 `untested` | `untested` |
| 两维都是 `mastered` | `mastered` |
| 其他情况 | `partial` |

家长侧可以展示为：

| 展示文案 | 数据含义 |
| --- | --- |
| 未测 | 两维均未测 |
| 已熟悉 | 熟悉度已通过，拼写未完成 |
| 待听写 | 熟悉度较好，需要验证拼写 |
| 拼写薄弱 | 纸面听写写错 |
| 复测中 | 任一维度正在 1/3/7 天复测链路中 |
| 已掌握 | 熟悉度和拼写都稳定通过 |

### 5.3 双功能联动抽词

每次会话仍然只测一个维度，但抽词会参考另一个维度。

如果本次测维度 X，另一个维度为 Y，优先级如下：

| 优先级 | 维度 X 状态 | 维度 Y 状态 | 说明 |
| --- | --- | --- | --- |
| P0 | `needs_practice` | `needs_practice` | 双重薄弱，最高优先 |
| P1 | `needs_practice` | 任意 | 本维度薄弱 |
| P2 | 到期复测 | 任意 | 间隔复测不漏 |
| P3 | `untested` | `reviewing` 或 `mastered` | 另一维已较熟，本维补盲区 |
| P4 | `untested` | `untested` 或 `needs_practice` | 新词或低基础词 |
| P5 | `reviewing` 未到期 | 任意 | 低优先推进中 |
| P6 | `mastered` | 任意 | 默认不选 |

P3 是双功能闭环的关键：它让“已经熟悉但没听写过”的词进入纸面听写，也让“写对但口头不熟”的词进入熟悉度测试。

### 5.4 纸面听写识别原则

纸面听写不能直接做开放式 OCR 后粗暴判定。推荐使用“候选词约束匹配”：

```text
本次会话有 20 个候选词
↓
OCR 识别纸面文本块
↓
按位置排序
↓
在本次候选词中计算编辑距离
↓
距离为 0：correct
距离较小但有差异：incorrect
无法可信对应：unclear
```

这样可以显著降低手写英文 OCR 的不确定性，也能识别类似 `Wensday → Wednesday` 这类可还原意图的拼写错误。

## 6. MVP 实施建议

### 6.1 推荐实施顺序

虽然最终设计是双功能闭环，但实现上建议分三步：

| 阶段 | 内容 | 目的 |
| --- | --- | --- |
| Phase 1 | 纸面听写单维闭环 | 先跑通“出词 → 纸上写 → 拍照 → 判定 → 更新拼写状态” |
| Phase 2 | 单词熟悉度口头闭环 | 加入口头中英互译，更新熟悉度维度 |
| Phase 3 | 双维联动抽词和综合掌握 | 实现 P3 补盲区、双维统计和首页推荐 |

原因：纸面听写最接近真实考试，也最能验证拼写短板；先跑通这条链路，可以尽快产生有价值的数据。

### 6.2 Phase 1 最小功能

Phase 1 只做纸面听写：

1. 英语工作台新增“纸面听写”入口。
2. 从个人词库抽 20 个词。
3. AI 逐个播报中文或英文。
4. 孩子在纸上按顺序写。
5. 家长拍照上传听写纸。
6. 云函数识别纸面结果。
7. 更新 `spelling` 维度。
8. 首页显示“拼写薄弱词”和“待复测词”。

### 6.3 Phase 2 最小功能

Phase 2 增加单词熟悉度：

1. 英语工作台新增“单词熟悉度”入口。
2. 从个人词库抽 20 个词。
3. AI 播报中文或英文。
4. 孩子口头回答另一个对应内容。
5. 语音识别后自动判定。
6. 更新 `familiarity` 维度。

### 6.4 Phase 3 最小功能

Phase 3 做闭环联动：

1. 抽词时参考另一个维度状态。
2. 优先补“熟悉但未听写”或“写对但口头不熟”的盲区。
3. 首页显示双维统计。
4. 单词详情展示熟悉度和拼写两个轨迹。

---

## 7. 给后续 AI 的使用建议

后续 AI 接手英语链路时，应遵守：

1. 英语当前主线是单词掌握，不要提前扩展到语法、阅读、作文。
2. 不要随机使用公共词库，必须基于钟青羽 PEP 个人词库。
3. 不要把“熟悉度正确”当成“已掌握”，拼写必须单独验证。
4. 不要让两个功能更新同一个状态，必须双维独立。
5. 不要把 `unclear` 当成错，语音/OCR 不确定应进入重测。
6. 纸面听写应使用候选词约束匹配，不要做开放式 OCR 猜测。
7. 第一阶段可以先实现纸面听写，随后再接入口头熟悉度和联动抽词。
8. 若未来要做时态或句型，应另建语法/句型数据模型，不要污染单词掌握状态。
