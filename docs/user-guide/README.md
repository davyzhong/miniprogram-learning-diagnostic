> 更新日期：2026-07-18
> 适用版本：当前 `main` 分支

这份导览面向第一次接触产品的家长，用界面说明“从哪里开始、如何看懂诊断、怎样完成验证”。开发与部署资料请返回[项目 README](../../README.md)或[文档中心](../README.md)。

## 1. 先看家庭今天最重要的事

<p align="center">
  <img src="images/01-family-workbench.png" alt="家庭学习工作台脱敏截图" width="300" />
  <img src="images/02-student-profile.png" alt="个人学习档案脱敏截图" width="300" />
</p>

**家庭学习工作台**按孩子展示当前最值得关注的信息。每张孩子卡的阅读顺序是：

1. 一行快捷入口，快速进入学习档案、学习记录、上传试卷和家长管理。
2. 每门学科最新的一份正式诊断报告；没有正式诊断的学科不占空间。
3. 基于诊断生成的优先行动和后续行动。
4. 紧凑的四项统计与三科学习状态。

**个人学习档案**只展开当前孩子的内容：每门学科最新诊断、诊断证据、行动建议和学习变化。AI 用量与成本估算不在个人档案重复展示，只从家庭首页顶部统一进入。

## 2. 进入学科工作台

<p align="center">
  <img src="images/03-subject-workbench.png" alt="数学学科工作台脱敏截图" width="280" />
</p>

学科工作台把诊断、行动和工具放在同一页。数学工作台提供最新报告、知识地图、学习卡点、任务包、验证卷与上传入口；文字和卡片采用紧凑布局，地图和处理队列不会挤占主要行动空间。

三门学科的基础导航一致，但内部学习方式不同：数学验证迁移能力，语文优先复测具体错项，英语分别追踪认词和拼写。

## 3. 阅读正式诊断报告

<p align="center">
  <img src="images/04-report.png" alt="正式诊断报告脱敏截图" width="300" />
</p>

报告页按照“结论 -> 证据 -> 行动”组织：

- 查看本次分析覆盖的试卷与错题证据。
- 查看不同学习卡点的出现频次、证据数量和置信度分数。
- 区分当前仍在出现、需要验证、已经改善和证据不足的项目。
- 直接进入对应的学习任务、知识地图或验证卷。

界面不会展示只供系统内部使用的 LP/BN 编码、数据库 ID、云文件地址或后端错误详情。验证卷编号如“数学-20260712-06”会保留，因为学科和日期对家长有实际意义。

## 4. 生成并完成验证卷

<p align="center">
  <img src="images/05-generate-verification.png" alt="生成验证试卷脱敏截图" width="270" />
  <img src="images/06-paper-preview.png" alt="验证试卷预览脱敏截图" width="270" />
</p>

1. 从报告、学科工作台或学习记录进入验证卷。
2. 系统按当前待验证目标组织题目；目标较多时自动分页。
3. 在预览页检查学生卷和答案页，打印后让孩子在纸上作答。
4. 拍照上传作答，系统把结果写回对应学习卡点和学习记录。
5. 如果生成任务长时间中断，页面会识别过期状态并提供恢复入口，不需要重复创建多份试卷。

数学通常使用同一卡点的新题验证迁移；语文必须包含此前识别错误的原字或原词，再加入有限的同音、同形、形近或多义扩展。

## 5. 用学习记录回看完整过程

<p align="center">
  <img src="images/07-learning-records.png" alt="学习记录时间线脱敏截图" width="300" />
</p>

学习记录把诊断报告、验证卷、作答反馈、英语练习和学习任务包按日期汇总。每条记录只展示家长能理解的标题、摘要、状态和行动，不透传内部编码。长时间中断且没有有效结果的分析记录可以由档案拥有者确认后归档。

## 6. 共同管理孩子档案

<p align="center">
  <img src="images/08-parent-management.png" alt="家长管理脱敏截图" width="300" />

档案拥有者可以邀请另一位家长加入，也可以移除共同家长。共同家长可参与上传、诊断和验证流程；成员管理等高风险操作只向档案拥有者开放。

## 7. 语文：原项复测优先

<p align="center">
  <img src="images/09-chinese-workbench.png" alt="语文工作台脱敏截图" width="200" />
  <img src="images/10-chinese-review-detail.png" alt="语文具体错项详情脱敏截图" width="200" />
  <img src="images/11-chinese-skill-task.png" alt="语文能力微任务脱敏截图" width="200" />
</p>

语文采用双轨设计：

- **记忆型错项**：错字、错词、读音、释义等按具体项目追踪。复测时必须再次出现原项目，不能只用同类新题代替。
- **能力型卡点**：阅读理解、概括、表达和写作结构等保留技能归纳，通过短任务练习和后续作品证据验证。

具体错项详情会展示原错误、正确内容、来源和复习状态；相似字词扩展只用于举一反三，不替代原项复测。

## 8. 英语：会认与会写分开追踪

<p align="center">
  <img src="images/12-english-workbench.png" alt="英语工作台脱敏截图" width="200" />
  <img src="images/13-english-confusion.png" alt="英语易混词巩固脱敏截图" width="200" />
  <img src="images/14-english-wrong-words.png" alt="英语错词本脱敏截图" width="200" />
</p>

英语当前聚焦词汇掌握，不试图一次覆盖完整英语学习体系：

- 个人词库保存孩子当前需要掌握的词。
- 认词练习通过看提示、口头回答和 AI 判定更新识别状态。
- 纸面听写按固定节奏报题，孩子完成后拍照上传，更新拼写状态。
- 今日英语优先安排会认不会写、到期复测或不熟的词。
- 易混词巩固与错词本帮助集中处理反复出错项目，但不会替代认词或听写证据。

## 9. 推荐的家庭使用节奏

| 时机 | 建议动作 | 预计时间 |
| --- | --- | ---: |
| 收到新试卷 | 拍照上传，等待正式诊断完成 | 3–5 分钟操作时间 |
| 当天或次日 | 阅读优先行动，完成一个短学习任务 | 10–15 分钟 |
| 练习后 | 生成并打印验证卷 | 2–5 分钟操作时间 |
| 孩子完成后 | 上传作答，查看是否改善 | 3–5 分钟操作时间 |
| 每周一次 | 回看学习档案和学习记录，选择下周重点 | 5–10 分钟 |

系统给出的置信度和行动建议用于辅助家庭学习安排，不替代教师的专业判断。发现试卷识别、错题归类或报告结论不准确时，应在报告页提交纠错反馈。
